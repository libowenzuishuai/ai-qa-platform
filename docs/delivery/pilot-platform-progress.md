## 已交付

- 接入首页显示环境、资料、用例批准、当前环境计划和运行记录五步状态及下一入口；记录存在不等于业务通过。
- 用例编辑支持前置条件、角色、优先级、步骤、结构化断言、预期类型/单位、数据与清理策略。保存新草稿版本，保留批准旧版与稳定步骤/断言 ID；新版本不能沿用旧执行计划。
- 开始任务前展示配置缺口和人工准备说明，服务端重复检查；环境变更、未批准用例、缺计划、缺凭据引用、未实现夹具能力阻止开始。只检查配置，不宣称账号已登录或业务前置条件已满足。
- 数据准备失败不执行业务操作；清理失败不再产生整体 PASS。已有业务失败仍保留 FAIL 优先级，清理错误作为事件记录。
- 自有运行器在下载及执行期间续租，取消/失联停止业务命令；清理逐个尝试本任务容器和卷。取消对账在 API/worker 使用同一实现，过期结果不能覆盖终态。
- 真实公共 GitHub 固定提交下载，经 Python CLI、Docker、平台 API、数据库与证据校验完成 Node/pytest 成功和失败对照；没有用本地源码替代下载。
