## 实际发现并修复

四项解析/差异缺陷先新增反例，原实现得到 **4 失败、9 通过**，修复后全部通过：

1. 单元格含嵌套表时跳过外层正文，导致规则原文丢失。现在外层正文和内层表均保留。
2. 页眉表格、首页/奇偶页页眉没有解析。现在提取这些部件、去重共享部件，并保留 LOW/UNPARSED 标记。正文和辅助坐标分离，解析器升级为 `python-doc-ingestion-1.3`。
3. 同位置同原文但 GOOD→LOW 时漏报；现在产出 uncertain。
4. 中间插行先按行号配对会把移动原文误判为改写；现在先识别原文对应，位置变化列 uncertain。

另完成：

- 差异入口拒绝失败解析、同版本、重复片段和跨文档引用；返回值经过共享形状与真实 bundle 引用校验。索引配对替代主要的逐片段两层扫描。
- C3 改为匹配旧侧引用；新增片段只提示重新提取。多条变化命中同一旧片段时全部保留，输出稳定排序和去重，避免后一次覆盖前一次。
- 低质量变化原来没有结构化规则条目，导致规则与用例复核链断裂；现在完整保留。
- 重复评测按本次新增调用计算用量，复用 context 不再重复累计历史 token；轮数必须为 1–100 的整数。
- 中文扫描表格的默认回归复用已提交 PDF，不再因当前机器缺字体而跳过。夹具重新生成仍需要中文字体。
- 新增 18 组 TS/Python 共用正反例：真实片段、跨版本、伪造引用、uncertain 缺新侧、未批准资产、遗漏/扩大影响范围、错误传导、质量降级和禁止自动批准。
