# 2.0 接管后的集成交付与剩余范围

更新：2026-09-28。接管基线 `a10dcec`，开发分支 `v2/autonomous-qa`。

## 发布结论

**开发预览，尚未完成完整 PRD 2.0。** 本轮把原来分散的组合内核、标准、能力、会话和证据接成可从页面操作的链路，并加入 MCP、缺陷复测、记忆实际消费和独立候选代码测试。它已经超过“只有 SDK 与占位接口”，仍不能宣传为通用替代测试人员或完整 Alpha 达标。

平台单测、合成缺陷对照、真实浏览器/容器与真实模型业务效果是不同证据。本轮无付费模型调用；没有把受控 HTTP 回包记成 Kimi 实测。

## 现在实际能做的事

|---|---|---|
| 组装并执行自己的工具流程 | 已授权能力 → 同 AST 画布/表单 → 拖动连接依赖 → 固定版本发布 → 发布 HarnessProfile → 选择环境和批准标准 → 运行会话 → 独立断言/证据 | 当前通用宿主运行确定性工具图；不能把未实现的模型/记忆策略填入配置假装启用。高级复合参数仍可能需要 JSON |
| 恢复被打断的组合执行 | 持久输入/意图/每次调用/回执，租约与 fencing，读取已核验回执；未知写入暂停核对 | 真实 SIGKILL 验收通过；不宣称任意写操作都能自动安全恢复 |
| 引入 MCP 工具 | 管理员安装单个固定工具、显式授权、Streamable HTTP 初始化/发现/调用、输入/输出 Schema 对比、取消 | 协议固定 2025-06-18；JSON/SSE 响应；无 OAuth 客户端流、stdio/旧 SSE；MCP 服务本身由管理员信任 |
| 防止构建漂移混入结论 | 冻结构建探针；每次能力调用前与最终判定前取回实际构建身份；不匹配停止；探针证据落库 | 无探针时允许诊断执行，业务检查可 pass，但对外报告为 review，不能当作已验证发布 |
| 追踪一个业务缺陷 | 确定性断言 FAIL → 候选 → 首败事实/证据 → 同标准独立复现 → 不同已核验构建修复验证 | 无证据、同一次运行、标准/组合/环境不同、未核验构建均拒绝升级；尚无自动根因定位/算法最小化 |
| 使用既往经验 | 自动检索本项目有效记忆、核对来源/版本/环境/标准/TTL，实际放入规划请求，记录采用或排除 | 接在现有草稿循环的模型规划请求中；used 只表示实际传入，收益为 unknown，人工收益评价有明确标签 |

| 确认测试不是“假有效” | 三个不同 SHA、同一补丁、首轮保留、无 skip/平台错误、原始报告字节复核、缺陷必须真实独立断言失败 | 导入/语法/运行时错误不算业务检出；Python bool 与 number 不混同；当前已知缺陷由调用方声明，非盲测独立真值 |

### 当前支持的组合标准

- Oracle 必须批准且内容哈希一致，已有会话固定旧版本。
- 确定性断言引用末端 READ 节点，实际数字按十进制比较；金额比较失败不能变成 not-equals 通过。
- 业务前置条件、角色限定、单位换算尚需专用验证器，当前宿主在副作用前明确拒绝；语义/视觉候选保留 REVIEW。
- 子流程固定完整版本闭包；同能力多实例不串输出；子流程包装节点的 condition/retry/map/repeat 暂不支持，内部节点受限策略可用。
- dry-run/replay 目前是内核接口，未完成产品页面/完整调试作业。不能把“检查组合”按钮称为完整演练。

## 关键修复

1. Graph 会话所有调用实际记账、保存原输入、验证回执，重复投递不重做完成的调用；未知写效果必须核对。
2. Profile、能力清单、Oracle 在运行时重新验证内容哈希；取消/暂停与过期租约均阻止继续提交。
3. 组合会话加入作业信封和恢复路径，通用 retry 入口不能绕开会话恢复策略。
4. 浏览器截图从受控目录按哈希登记为本次运行的 Artifact；截图丢失也使报告降级，不能只留下一个文件路径。
5. Finding 的来源证据、支持/反对证据和人工确认验证实际文件；证据过期也拒绝确认；驳回必须写原因。
6. 测试补丁审核/驳回/派发使用同项目锁；不能在并发驳回后继续批准。候选文件只能新增到专用测试目录，拒绝覆盖、路径穿越和哈希不符。
7. 真实 SIGKILL 测试改为直接启动 Node loader，杀掉实际 worker，而非只杀仍留下子进程的启动器。
8. API/worker 镜像构建显式安装 OpenSSL，API 运行镜像也保留运行依赖；不能依赖 Prisma 对缺失 libssl 的猜测。

## 入口与升级

先备份，再在目标环境应用纯新增迁移 `20260928020000_v2_test_patch_review`，并重建 Prisma 客户端。前一轮恢复迁移 `20260928010000_v2_session_recovery` 也必须已应用。本轮未重置开发库或改写旧迁移。

```sh
pnpm install --frozen-lockfile
pnpm --filter @ai-qa/api exec prisma generate
pnpm --filter @ai-qa/api exec prisma migrate deploy
```

随后重启 API、worker、web、intelligence。使用现有登录和项目权限。

- 工作空间侧栏：**智能测试 · 2.0 预览**。
- 总入口：`/space/<项目>/autonomous`；交付任务、组合执行、代码测试分别进入现有真实链路，合成演示折叠显示。
- 组合编辑/运行：`/space/<项目>/composer` / `composer/run`。
- 运行详情：`/v2/sessions/<会话>`；状态、业务判定、构建核验分别展示。
- 代码测试：`/space/<项目>/test-patches`；Python 服务需配置，生成本身不调用模型。执行需已授权的 Node/Python 自有运行器。
- 缺陷调查：`/space/<项目>/findings`。
- 构建探针：沿用环境 runtime 的 `buildProbe.path` / `field`；目标测试服务应返回真实、不可变构建标识。
- MCP 安装清单：`protocol: mcp-http`，`entrypointRef` 为所选工具名，管理员固定 endpoint 与完整输入/输出 Schema。安装与授权是两步；未知写回执不得自动重放。

MCP 依据：[官方 Streamable HTTP 规范](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)、[官方工具调用规范](https://modelcontextprotocol.io/specification/2025-06-18/server/tools)。
