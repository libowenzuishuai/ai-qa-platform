## 剩余工作的性质

代码扩展仍包括跨资料语义覆盖/设计图、多观察器、广泛接口及性质测试生成、变异分析、完整远程认证接管与部分复杂组件适配；不能把这些说成只差账号。

外部验收需要真实授权项目、独立标准与缺陷真值、模型费用额度和 GitHub App 配置。开发分支与 main 保持分离，完整发布门通过前不发布正式 2.0。

测试继续使用临时数据库和隔离目标；不读取/提交开发密钥，不重置日常开发数据库，不重放未知业务写操作。
