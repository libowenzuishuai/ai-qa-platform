## 主要修复

1. **源码实际未生效**：删除 API 源目录内 18 个旧 `.js` / `.js.map` / `.d.ts` 编译产物，避免运行器优先加载陈旧代码；增加忽略规则，生产编译仅输出 dist。
2. **两套快照协议**：合入 B 正式契约与比较算法；平台从同项目仓库快照冻结来源，复核扫描清单、原字节、解析片段与排队漂移，旧不可信协议拒绝写入。
3. **仓库更新无法接变更复核**：同仓库/子目录/路径使用连续资料版本；同内容复用最近版本，内容回退也新建版本；相同字节的不同仓库和路径不再混用来源。并发导入在项目锁下分配版本。
4. **长文档切片未真正发送**：实际发送码点切片，独立验证全部正文覆盖及预算；块提交联合校验 job/attempt/lease owner；取消与失联释放自己的块；合并不改写业务字段，正确重编号冲突和澄清引用；完整结果通过原 RULE_EXTRACTION 路径保存 DRAFT。
5. **组合工作流仅看数组顺序**：按依赖 DAG 执行；冻结实际能力版本/节点/配置哈希；限定引用与映射类型、审批/账号准备不能条件跳过；已有真实 child job/run/code-check 接入，人工确认根据能力而非自定义节点名恢复。
6. **新能力/模板版本并发 500**：项目事务锁分配版本，并与审计同事务提交。
7. **目标规划只在 Python**：新增 durable GOAL_PROPOSAL 作业；固定服务端资料/环境/能力输入，调用前与落库前复核；取消和输入漂移不能生成可用草稿；模型调用记录保留。
8. **证据过期仍能下载，统计沿用旧 PASS**：到期拒绝下载；项目管理员显式开启执行证据保留策略；终态材料按单文件清理并保留记录与审计；资料来源、活跃运行和共享存储不删除；统计调用同一 reporting 重新核对证据，单列历史入库状态。
